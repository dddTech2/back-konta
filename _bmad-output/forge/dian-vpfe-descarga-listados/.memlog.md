goal: Revisar la viabilidad técnica, riesgos y casos borde del flujo
updated: 2026-09-13T12:52

- (direction) Objetivo: Evaluar viabilidad de automatización Playwright para autenticación por token en correo y descarga de reportes DIAN VPFE
- (assumption) El correo llega a Stalwart Mail Server (token@example.com) y puede ser consultado vía IMAP/JMAP o API en tiempo real
- (crack) Riesgo de bloqueo o desacople si la consulta de correo se hace por UI en vez de IMAP/API directo
- (crack) Comportamiento del enlace mágico de DIAN: expiración de token y si requiere compartir el mismo BrowserContext
- (decision) Lectura de token por conexión directa / API / IMAP a Stalwart Mail Server (evita automatizar webmail por UI)
- (lock) El flujo de correo se resuelve desacoplado del navegador: polling IMAP/API con timeout configurable y extracción de enlace vía regex/HTML parser
- (crack) Límite de rango de fechas en #export-range: la DIAN suele restringir la descarga a periodos específicos (ej. máx 30 días)
- (crack) Mecanismo de entrega de Excel: ¿Descarga directa por evento 'download' de Playwright o encolamiento en tabla de peticiones?
- (decision) Comportamiento de #action-left / #action-right: desplaza el rango de fechas un día a la izquierda/derecha. Se mapea el valor actual de #export-range y se itera hasta la fecha objetivo.
- (lock) Alcance Milestone 1: Desde login inicial hasta confirmación de encolamiento (botón 'SI' + cierre de modal '×'). La descarga efectiva desde la tabla inferior queda para Milestone 2.
- (note) El sistema de DIAN encola la petición en una tabla inferior asíncrona.
- (event) session complete - idea hardened and transitioned to bmad-build
