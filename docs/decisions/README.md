# Registro de Decisiones de Arquitectura (ADRs)

Este directorio documenta las decisiones técnicas y arquitectónicas significativas tomadas en el proyecto **DianAutomation**.

El objetivo de los ADRs (*Architecture Decision Records*) es registrar el **por qué** detrás del diseño: el contexto del problema, los requisitos, las alternativas descartadas y las consecuencias a largo plazo, de modo que futuros desarrolladores y agentes de IA comprendan las razones que motivaron cada solución.
